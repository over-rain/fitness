# 运行流程（文字版流程图）

> 2026-10-16 整理。对应代码：`code/app.py`（单文件服务，零依赖）。

## 0. 启动

```
python code/app.py
 ├─ 读 code/config.json（无则从 config.example.json 生成）   [含 api_key，不入 git]
 ├─ init_db：建 meals 表 + 迁移 fat_g/carb_g 列              [data/fitness.db]
 └─ 0.0.0.0:8124 监听，打印局域网地址
      └─ 手机访问 http://<电脑IP>:8124（公网走内网穿透，见 05 §3.2）
```

## 1. 主页面（剩余额度总览）

```
打开页面
 ├─ 读 localStorage 记住的用户（邶风/gagayouna）
 └─ GET /api/today?user=X
      ├─ 查 SQLite：今日该 user 的全部记录
      ├─ 查 data/profiles/<user>.json → daily_target / protein_target
      ├─ 计算：已吃=Σkcal、剩余=目标-已吃、蛋白合计
      ├─ dinner_tip：有午餐记录或已过 13 点 → 晚餐建议(剩余×90%，单餐≤800)
      └─ 前端渲染：剩余大卡+进度条(>85%变红)、晚餐建议、明细列表
           明细 = 按餐次分组(早→午→晚→加)
                组标题 = 餐次+建议区间(目标×25/35/30/10%±15%)+本组合计
                每行 = 缩略图(/photo/<id>) + 食物名 + 千卡 + ›
```

## 2. 文字快捷记录（说话记账）

```
输入一句话 → 回车/发送
 └─ POST /api/meal {user, text}
      ├─ 取今日已有记录(≤10条)作为上下文 → LLM(glm-5.3-flash, 网关 Anthropic 协议)
      ├─ 模型输出 JSON：{action, id, items[]}
      │    action=record  → 逐项走热量降级链：查《常吃食物热量表》[表] → 未命中模型估[估]
      │    │               → INSERT meals（禁止 LLM 心算，求和全在服务端）
      │    action=correct → 按 id 原地 UPDATE（裸描述式更正，如 咖啡→燕麦拿铁）
      │    │                id 无效 → 降级为 record
      └─ 回复三行卡片：已记录/已更正 + 今日已吃/目标 + 剩余
```

## 3. 拍照记录（分析结果页，薄荷式）

```
📷 选照片
 ├─ 前端读 EXIF DateTimeOriginal → 拍摄小时 → 默认餐次（读不到→按当前时段）
 ├─ canvas 压缩到 ≤1024px JPEG（原图 1.5MB → ~200KB）
 └─ 跳转分析结果页（不入库！）：
      POST /api/analyze {user, image} → LLM 识别 → items[]（含 kcal/蛋白/脂肪/碳水 + [表]/[估] 标记）
      页面展示：‹返回｜今天·餐次▼(可改)｜照片｜逐项名称/份量/千卡｜汇总大字+三宏量
      │
      ├─ [✏️ AI 修正] → 弹窗：文字描述 和/或 传剩余照片
      │      POST /api/analyze {image(剩余图或原图), text, prev=当前items}
      │      → 模型按修正要求调整（吃一半→减半；剩余→输出「扣回:」负数项）
      │      → 页面原位刷新，可反复修
      │
      └─ [💾 保存记录] → POST /api/save {user, meal_type=页面所选, items, image}
             ├─ INSERT meals（fat/carb 列随行）
             ├─ 照片存档 data/meals/record_<id>.jpg（明细缩略图用）
             └─ 回主页面，剩余额度即时更新
```

## 4. 修账（明细列表）

```
点右侧「千卡 ›」  → 弹窗改 kcal（区间同步 ±10%）
行右滑 → 滑出浅红「删除」→ 点击删除（记录+照片文件一起删）
餐次归属错误 → 目前走文字更正（"刚那张是午餐"）或删除重记
```

## 5. 身体档案（⚙️ 设置）

```
⚙️ → 弹窗[个人信息|通用]
个人信息：名称/性别/年龄/身高/体重/目标体重/周练天数
 └─ POST /api/profile → 校验(年龄10-100等) → fitness_lib.plan() 重算
    （Mifflin-St Jeor）→ 写回 profiles/<user>.json → 首页额度立即按新线
通用：暂空，预留 访问码/模型切换
```

## 6. 数据与外部依赖

```
数据：data/fitness.db（唯一账本，每周手动拷贝备份）
      data/profiles/*.json（档案+热量线）
      data/常吃食物热量表.md（降级链第①档，改完即生效）
      data/meals/*.jpg（记录照片，随记录删）
外部：火山方舟 coding 网关（Anthropic 协议 /v1/messages，glm-5.3-flash 视觉+文本）
      └─ 思考型模型：max_tokens 3000 + 空正文重试一次；高峰 10~30s 属正常
安全：access_code 为空=无鉴权（局域网自用）；公网暴露前必须设置（config.json）
```
