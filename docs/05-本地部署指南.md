# 本地部署指南 —— 拍照记餐 + 剩余额度（方案②：本地 + 内网穿透）

> 配套《01-需求文档.md》§10 决策（2026-10-15 拍板：本地开发 + 内网穿透，训练暂缓）。
> 代码：`code/app.py`（零依赖标准库）+ `code/config.json`；数据：`data/fitness.db`（SQLite）。

## 1. 快速启动（已验证可用）

```
cd code
python app.py
```

启动后终端会打印可访问地址。当前为 **MOCK 模式**（不调真实模型，任何输入记 400kcal 示例值），用于验证链路。

## 2. 接入真实模型（5 分钟）

已验证可用的两条路（2026-10-15 实测）：

**A. 火山方舟 coding 网关（当前在用）**：Anthropic 协议 `/v1/messages`，glm-5.3-flash 视觉识别质量高（香蕉 105kcal 精准、便当拆 4 项合理）。config：
```json
{"llm": {"protocol": "anthropic", "base_url": "https://ark.cn-beijing.volces.com/api/coding",
         "api_key": "ark-...", "model": "glm-5.3-flash"}}
```
注意：该网关**只认 Anthropic 协议**（OpenAI 格式无响应），且模型别名（deepseek-v4-flash 等）在标准 v3 口不可用。

**B. 智谱开放平台**：OpenAI 协议，glm-4v-flash 免费：`base_url: https://open.bigmodel.cn/api/paas/v4`，`model: glm-4v-flash`（省略 protocol 行）。

步骤：编辑 `code/config.json` 填 key → `mock` 改 `false` → 重启 → 冒烟回归 `python scripts/smoke_test.py`（17 项应全过）。

## 3. 手机访问

### 3.1 局域网（在家）

手机连**同一 WiFi** → 浏览器打开终端打印的 `http://<电脑IP>:8124` → 菜单里「添加到主屏幕」。
（本机有多个虚拟网卡时逐个试打印出来的 IP，能打开页面的那个就是）

### 3.2 内网穿透（出门也能用，方案②核心）

以 cpolar 为例（免费版够用）：

1. 注册 cpolar → 下载 Windows 客户端 → 登录
2. 命令：`cpolar http 8124` → 得到公网地址（如 `https://xxx.cpolar.io`）
3. 手机打开该地址 → 加到主屏幕。**免费版地址重启会变**，变了重新加一次
4. ⚠️ **公网暴露前必做**：`config.json` 里设 `access_code`（自定义一串字符），重启后页面首访会要求填码（浏览器会记住）。否则任何拿到链接的人都能写你的账本
5. 想要固定域名：cpolar 保留域名（收费）或换花生壳/tailscale（后者手机装 app，走私有网络，更安全）

## 4. 日常使用

- 顶部切换 邶风 / gagayouna（记忆在各自手机里）
- 拍照或说一句 → 三行卡片（已记录/今日已吃/剩余）
- 明细列表可改热量、删记录（更正规则：改原记录，不新增）
- 热量角标：`[表]`=查自《常吃食物热量表》，`[估]`=模型估，估的更正后建议顺手补进表
- 电脑关机/服务停 = 全家不可用（方案②的固有代价，出门前别关）

## 5. 维护

| 事项 | 做法 |
|---|---|
| 冒烟测试 | `python scripts/smoke_test.py`（改动代码后必跑） |
| 数据备份 | 复制 `data/fitness.db` 即可（建议每周一拷，01 §9 抗丢失要求） |
| 体重变化 ±2kg | 页面右上角 ⚙️ → 改体重 → 保存自动重算热量线（写入 `data/profiles/*.json`） |
| 热量表扩充 | 直接编辑 `data/常吃食物热量表.md` 表格行，保存即生效（无需重启） |

## 6. 故障排查

| 症状 | 处理 |
|---|---|
| 手机打不开页面 | 确认同 WiFi；Windows 防火墙放行 8124 端口；换终端打印的另一个 IP |
| 记餐返回"未配置 api_key" | 填 `config.json` 或临时 `mock: true` |
| 识别失败/超时 | 看服务端终端报错；免费模型偶发限流，重试一次 |
| 端口被占 | `config.json` 改 `port` |
