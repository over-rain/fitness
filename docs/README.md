## 文档纪律

1. **单一事实源**：产品边界只认 01；操作步骤只认 02；被验证的设计只认 03——同一信息不写在两处，交叉引用用《编号-名称》格式
2. **状态必须更新**：验收每过一项，更新 03 的 §4.5；方案变更先改 01 再同步下游
3. **命名规范**：`两位序号-中文名.md`；新文档进目录要同时更新本索引
