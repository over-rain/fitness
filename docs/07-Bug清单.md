> [!bug] BUG-01 🔴 线上照片缩略图全部不显示
> **记录日期**：2026-10-22（用户实测报告 + 本地端到端复现）
>
> **现象**：线上 http://106.14.174.18/ 今日明细里，有照片的记录缩略图全是 broken image（截图：米饭/清汤/红烧肉等）；本地开发机同一份代码显示正常。
> **影响**：==线上用户完全看不到自己拍了什么==，拍照记录的核心闭环断了一半。
> **原因**：明细缩略图用 `<img src="/photo/<id>">`，而 `<img>` 是浏览器原生请求，==无法携带 `X-Access-Token` 请求头==；`/photo/` 路由开了访问码校验（`_authed()`，app.py:1248-1250）。前端只在 `api()` 的 fetch 里带 token，`<img>` 不经过它 → 线上（配置了 `access_code`）全部 404 空图；本地没设访问码 → `_authed()` 恒真，所以正常。
>
>> [!success] 验证记录（生产代码 + 临时端口，`access_code="secret123"`，照片真实存在）
>> 无 token（`<img>` 的真实情况）→ `404, 0字节`；带 token（fetch 的情况）→ `200` 正常返回照片
>
> **修复建议**（三选一，均只动一处）：
> 1. 前端改：缩略图经 `api()` fetch 转 blob/data URL 再赋 `<img src>`（改 refresh()/openEdit() 两处）
> 2. 后端改：`/photo/` 支持 `?t=<访问码>` 查询参数兜底（URL 会进日志，安全性略弱）
> 3. 后端改：照片文件名带随机不可猜 token，`/photo/` 免鉴权但 URL 不可枚举（顺带解决 BUG-03）
>
